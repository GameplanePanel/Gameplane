# Download backups as archives and restore from an uploaded archive

A finished restic backup can now be downloaded as a `.tar.gz` or `.zip` file, with a manifest that names the server, game and template. A server can be restored from an uploaded archive, either one Gameplane made or a plain copy of a server's data folder. Uploads are checked on a temporary staging volume before any server data changes. Downloads and uploads need the existing `backups:read` and `backups:restore` permissions. The new Helm values are `backups.maxUploadSize` (default `20Gi`), `backups.uploadStagingStorageClass` (default: the cluster's default storage class), `backups.maxConcurrentExports` (default 3) and `backups.exportTTL` (default 1h). The chart installs the new `BackupExport` CRD on upgrade. See the Backups section of `docs/operator-operations.md`. [PR #1117](https://github.com/GameplanePanel/Gameplane/pull/1117)
