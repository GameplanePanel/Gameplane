# Download backups as archives and restore from an uploaded archive

A finished restic backup can now be downloaded as a `.tar.gz` or `.zip` file (`backups:read`), and a server can be restored from an uploaded archive, either one Gameplane made or a plain copy of a server's data folder (`backups:restore`). Uploads are unpacked and checked on a temporary staging volume, and nothing on the server changes until you confirm. The chart installs the new `BackupExport` CRD on upgrade and adds the Helm values `backups.maxUploadSize` (default `20Gi`), `backups.uploadStagingStorageClass` (default: the cluster's default storage class), `backups.maxConcurrentExports` (default 3) and `backups.exportTTL` (default 1h). See "Backup archives: download and upload" in `docs/operator-operations.md`. [PR #1117](https://github.com/GameplanePanel/Gameplane/pull/1117)
