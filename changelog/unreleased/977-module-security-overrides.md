# Per-server security overrides with module defaults

Modules can now set the run-as user, run-as group, filesystem group and volume ownership check for their game, and a server owner with the new `servers:security` permission can override each one in an Advanced section of the create-server wizard and the server's Settings. Overrides apply on the next restart; saving never restarts a server. Root overrides (user or group 0, or the image's default user) are off by default and are allowed per cluster under Clusters, cluster, Configuration, Security. The volume ownership check now defaults to "only when wrong", which starts servers with large volumes faster. Run `helm upgrade` so each cluster gets its security settings.
