# Share link details and module catalog filters

Public share cards show the panel’s instance name and the server description beneath the centered server name. The connection address prefers a published game hostname when one is available. In Modules, the source and workload cluster selectors are under Filters beside search, and categories wrap to fit the page. Cluster cards now offer View Details, View Nodes and View Servers in that order. [PR #1147](https://github.com/GameplanePanel/Gameplane/pull/1147)
