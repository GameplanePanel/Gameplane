# Server file manager

Expand folders, link directly to a file and switch between open editor tabs.
Edits autosave in order and failed saves remain available for retry during
the session. Select files and folders to download a ZIP, save an archive on
the server or delete them together. Repeating a deletion while it is in
progress shares the pending request. [Issue #935](https://github.com/GameplanePanel/Gameplane/issues/935)
