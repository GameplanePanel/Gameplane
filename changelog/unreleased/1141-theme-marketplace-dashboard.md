# Theme marketplace in the dashboard

Users can browse the theme catalog, preview a theme across the dashboard before installing it, and install, update, select and remove themes from their own settings. Admins and roles with `themes:manage` get a Theme sources page to add, edit, refresh, enable and remove sources. A private source names a pull secret (OCI) or credentials secret (git, HTTP) that the admin creates, the same way as module sources. [PR #1141](https://github.com/GameplanePanel/Gameplane/pull/1141)
