# SFTP access to game server files

SFTP is an optional component, off by default: set `sftp.enabled=true` (and `sftp.serviceType`, `sftp.publicAddress` if you need outside access) to browse, upload and download server files with FileZilla, WinSCP or `sftp`. Every login and file change goes through the API as the signed-in user, so the Files tab permissions and the audit log apply, with source `sftp`. Users add SSH keys and generate a SFTP password under Settings, SFTP; admins can revoke them in Users, and remote clusters get their own endpoint under Clusters. Uploads from SFTP and the Files tab now stream and are capped by the new `files.maxUploadSize` value (default `20Gi`), and `operator.filesIdleTimeout` (default `10m`) sets how long a file-only pod stays up for a stopped server. Setup and troubleshooting: [docs/sftp.md](../../docs/sftp.md). [PR #1074](https://github.com/GameplanePanel/Gameplane/pull/1074)
