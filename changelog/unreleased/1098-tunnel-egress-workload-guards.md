# Breaking: Tunnel relays can only dial public addresses; sidecar ports and account overrides are refused

Outside `networkPolicies.tenantIsolation`, a tunnel relay now reaches its provider (frp, Tailscale, playit) on public addresses only, and reaches its advertised ports on its own game server only. A frp server set by IP address keeps working. Before upgrading, add a LAN frp server reached by hostname to `networkPolicies.tunnelEgress.allowCIDRs` (for example `192.168.1.20/32`). A template can no longer advertise TCP 8090, 9090 or 9091, the agent and capture ports. A server's `spec.serviceAccountName` can no longer name another component's or another server's ServiceAccount, or a Helm-managed one. The new `operator.allowedImageRegistries` setting can limit `spec.image` overrides to chosen registries. Playit tunnel pods restart once on upgrade. [PR #1098](https://github.com/GameplanePanel/Gameplane/pull/1098)
