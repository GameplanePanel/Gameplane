# Browse modpacks for every loader

The Modpacks tab now has an "All loaders" switch. Turned on, it lists packs for every loader and Minecraft version, not only the ones that match the server's current version, so a Fabric server can find NeoForge packs such as FTB Evolution 2. The version picker then shows which server version each pack version runs on. Installing a version for another loader or Minecraft version also switches the server to that version, and the confirmation says so. [PR #1114](https://github.com/GameplanePanel/Gameplane/pull/1114)
