# CurseForge and FTB modpacks with pinned versions

The Modpacks tab gains CurseForge and Feed The Beast (FTB) registries next to Modrinth, with a version picker and a pinned version for every pack, so a restart never upgrades a pack by surprise. A pack is recorded in the new `GameServer.spec.modpack` field and applied by the operator, with an optional backup first; `DELETE /servers/{name}/modpack` removes it and empties the mods folder. Packs that include files CurseForge blocks from automatic download list them with links, to be uploaded to `downloads/` in the Files tab. Servers that already run an unpinned Modrinth pack are adopted and pinned to their installed version at the next quiet moment (no players online) with one restart. Module authors get the new template fields `versionEnv`, `apiKeyEnv`, `needsKeyImageTags`, `missingFilesPath`, `adoptVersionFile`, `modpacksOnly` and the `ftb` provider, see [Modpacks](../../docs/module-authoring.md). Sharing the admin's CurseForge key with servers on images without a built-in key is not available yet; see [the residual risk](../../docs/security.md#sharing-the-curseforge-key-with-game-servers).
