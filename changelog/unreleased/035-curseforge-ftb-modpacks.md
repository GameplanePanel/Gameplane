# CurseForge and FTB modpacks with pinned versions

The API can install CurseForge and Feed The Beast (FTB) modpacks alongside Modrinth ones, each pinned to a chosen version so a restart never upgrades a pack by surprise. The operator applies a pack recorded in the new `GameServer.spec.modpack` field, with an optional backup first; `DELETE /servers/{name}/modpack` removes it and empties the mods folder. Packs with files CurseForge blocks from automatic download are listed with links and the `downloads/` path to upload them to. Servers already running an unpinned Modrinth pack are pinned to their installed version at the next quiet moment (no players online), with one restart. Admins can opt in to sharing the CurseForge key with servers on images without a built-in key; see [the residual risk](../../docs/security.md#sharing-the-curseforge-key-with-game-servers). Module authors get new template fields and the `ftb` provider, see [Modpacks](../../docs/module-authoring.md).
