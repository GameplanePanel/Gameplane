The Gameplane chart now requires Kubernetes 1.30 or later. The native API stores its credentials and uploaded module ConfigMaps in a dedicated namespace. Before upgrading, migrate existing credentials, uploads and module locale ConfigMaps, remove legacy service-account token Secrets, and bind each private HTTP or Git module credential to its exact source URL. Follow the [native credential upgrade instructions](../../docs/install.md#upgrading-native-api-credentials).
