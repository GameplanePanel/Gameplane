# Theme marketplace API and the themes:manage permission

The API can now index theme sources (OCI registry, git, HTTP archive or local folder), list their themes, and let each user install, update and remove themes for themselves. Theme sources are managed by admins and by roles granted the new `themes:manage` permission. The official theme source is configured under the new Helm value `themes.officialSource` (`enabled`, `url`, `themes`, `verify.enabled`, `verify.cosignPublicKey`), is verified with the same cosign key as modules, and is reconciled from the chart on every start. Set `themes.officialSource.enabled: false` on air-gapped installs that do not mirror it. [PR #1135](https://github.com/GameplanePanel/Gameplane/pull/1135)
