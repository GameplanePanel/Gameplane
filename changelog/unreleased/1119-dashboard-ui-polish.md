# Clearer Servers, Logs and Resources screens

The Servers summary cards each have their own colour and show warnings as an
amber badge, row actions are easier to see, and every status pill now has a
coloured dot. Buttons, inputs and tabs use 12 px corners, and tab lists no
longer wrap. The Logs toolbar has two rows with coloured log levels and counts.
Resource sliders fill up to the handle, and storage size is entered as a number
and a unit. [PR #1119](https://github.com/GameplanePanel/Gameplane/pull/1119)
