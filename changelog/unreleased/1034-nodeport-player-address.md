# Show the player address for NodePort servers

The dashboard now shows and copies the game's hostname or its serving node's external IP together with the assigned NodePort. If your nodes have no external IP, set the hostname players use in **Settings → Networking**. See [Connecting to a NodePort server](../../docs/networking.md#connecting-to-a-nodeport-server).
