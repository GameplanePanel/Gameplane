# Module updates: Minecraft modpacks, Minecraft Proxy, Valheim player count

The official modules now include [minecraft-java](https://github.com/GameplanePanel/module/blob/main/minecraft-java/README.md) 2.13.0 with CurseForge and FTB modpack installs and version pins (needs Gameplane 0.5.0), a new [Minecraft Proxy](https://github.com/GameplanePanel/module/blob/main/minecraft-proxy/README.md) module, a [Valheim](https://github.com/GameplanePanel/module/blob/main/valheim/README.md) player count read from the Steam query, and risky-setting markers with an ownership check for module security overrides. The new versions appear in the module catalog after the modules are republished; an installed module keeps its current version until you upgrade it. [PR #1064](https://github.com/GameplanePanel/Gameplane/pull/1064)
