# Module updates: Minecraft modpacks, Minecraft Proxy, Valheim player count

The official modules now include minecraft-java 2.13.0 with CurseForge and FTB modpack installs and version pins (needs Gameplane 0.5.0), a new Minecraft Proxy module, a Valheim player count read from the Steam query, and risky-setting markers with an ownership check for module security overrides. The new module versions reach existing installs after the modules are republished. [PR #1064](https://github.com/GameplanePanel/Gameplane/pull/1064)
