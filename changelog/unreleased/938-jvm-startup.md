# Stage game settings for the next start

Template authors can set `applyOnRestart` on environment fields. Saving or clearing
these fields leaves the running Pod in place. Adopting the updated template can
restart an existing server once. Minecraft Java settings now preview the initial
and maximum heap independently and show when saved changes will take effect.
[Issue #938](https://github.com/GameplanePanel/Gameplane/issues/938)
