# Telemetry receiver resists report spam

The telemetry receiver now limits how many `/ingest` requests one source can send per minute, counting refused and malformed reports (`INGEST_SOURCE_PER_MINUTE`, default `60`, `0` turns it off). The first report of a new install ID must now carry about a second of proof-of-work (`INGEST_CLAIM_POW_BITS`, Helm `api.telemetry.receiver.ingestPow.claimBits`, default `20`, `0` turns it off), so bots can no longer create fake installs for free; installs already known to the receiver never solve anything for it, and Gameplane installs from v0.4.0 on handle the challenge automatically. Junk version strings can no longer fill the 128 version labels: a version reported more often takes the slot of the least reported one. Request headers are capped at 16 KiB, and the `AUTH_TOKEN` check no longer reveals the token's length. [PR #1090](https://github.com/GameplanePanel/Gameplane/pull/1090)
