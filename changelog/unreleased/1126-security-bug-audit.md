# Breaking: security and bug fixes from the November code audit

The API no longer lets a user with servers:write delete another person's server through a forged ownerReference, keys login throttling on the IPv6 /64 and answers 503 instead of stalling when too many sign-ins queue, refuses readiness probes that arrive through a proxy, stops writing audit rows for unknown routes, and no longer turns off every sign-in method when an SSO role mapping is reset before any auth settings were saved. The operator no longer adopts a `<server>-rcon` Secret it did not create (delete or rename such a Secret so a new password is generated), uses the RCON or admin password a user typed into the server settings (Farming Simulator 25, Left 4 Dead 2, Squad, The Isle) instead of silently replacing it, backs up servers with long names, caps module layer sizes and checks signatures through the SSRF guard. Dashboard file uploads now follow `files.maxUploadSize`, leaving the Files tab saves pending edits, archive restores refuse corrupted or crafted tar.gz files, SFTP no longer empties an existing file that a client opens without write or truncate flags, Minecraft transfer joins wake sleeping servers, and the FiveM, Farming Simulator 25 and Euro Truck Simulator 2 images install and start their server.
