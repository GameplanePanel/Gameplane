# Security and bug fixes from the November code audit

The API no longer lets a user with servers:write delete another person's server through a forged ownerReference, keys login throttling on the IPv6 /64 and answers 503 instead of stalling when too many sign-ins queue, refuses readiness probes that arrive through a proxy, and stops writing audit rows for unknown routes. The operator no longer adopts a `<server>-rcon` Secret it did not create (delete or rename such a Secret so a new password is generated), backs up servers with long names, caps module layer sizes and checks signatures through the SSRF guard. Dashboard file uploads now follow `files.maxUploadSize`, leaving the Files tab saves pending edits, archive restores refuse corrupted or crafted tar.gz files, Minecraft transfer joins wake sleeping servers, and the FiveM, Farming Simulator 25 and Euro Truck Simulator 2 images install and start their server.
