# MCP tokens page in the dashboard

Every signed-in user can now create, copy and revoke personal MCP tokens under Settings, MCP tokens (also in the user menu). A token is shown once, together with a ready-to-paste MCP client configuration, and can only read what its owner can read. Admins with `users:read` see a user's tokens from the user's row menu in Users & RBAC, and can revoke them with `users:manage`. [PR #1067](https://github.com/GameplanePanel/Gameplane/pull/1067)
