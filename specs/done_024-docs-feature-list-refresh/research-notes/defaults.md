Relevant facts for the postgres tag:
- `api/internal/db/db_postgres.go` only builds with `-tags postgres`. The values comment says the published API image is built without it (`charts/gameplane/values.yaml:157-160`), and `api.db.driver` says postgres is experimental (line 155).
- The chart only sets `driver: sqlite` by default (line 155) with DSN at line 156.

Only the `postgres` tag and the platform tags (`unix`, `linux`) are user-visible feature differences. The `!ignore_autogenerated` tag is a generator marker.
