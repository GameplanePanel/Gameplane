# Contract: Language Pack Format

**Feature**: `019-localization-language-packs` | **Binding modules**: `i18n/`, `web/`, `modules/`, `gp-module/` | **Status**: Binding

## 1. App packs (`GameplanePanel/Gameplane`)

```text
i18n/locales/
├── en/
│   ├── app.json     # reference: generated (dashboard via formatjs extract, server.* via i18n-check --sync-server); never hand-edited
│   └── meta.json
├── fr/
│   ├── app.json     # translation (Weblate or PR)
│   └── meta.json
└── <tag>/…
```

### 1.1 `app.json` (Format.JS JSON, UTF-8, keys sorted, 2-space indent, trailing newline)

```json
{
  "web.servers.list.empty": {
    "defaultMessage": "No servers yet. Create one to get started.",
    "description": "Servers page, empty state body. Max ~80 chars."
  },
  "web.servers.list.count": {
    "defaultMessage": "{count, plural, one {# server} other {# servers}}",
    "description": "Servers page header. count = number of servers shown."
  },
  "server.namespace_forbidden": {
    "defaultMessage": "namespace not permitted",
    "description": "API error when the user's role does not cover the namespace."
  }
}
```

In a translation file `defaultMessage` holds the translated text; `description` is optional and ignored; an optional `sourceHash` (first 12 hex of SHA-256 of the English `defaultMessage` the translation was made from) is written by `i18n-check --stamp` (research R8).

### 1.2 `meta.json`

```json
{
  "tag": "fr",
  "nativeName": "Français",
  "englishName": "French",
  "direction": "ltr",
  "credits": [{ "name": "Jane Doe", "url": "https://github.com/janedoe" }]
}
```

`tag` MUST equal the directory name. Unknown keys are rejected.

## 2. Message rules (enforced by `i18n-check`, see [check-tool.md](./check-tool.md))

1. ICU MessageFormat; arguments `{name}`, `{n, number}`, `{d, date, short}`, `{n, plural, …}`, `{x, select, …}`; `#` inside plural.
2. A translation's argument names MUST equal the English entry's (order free; plural categories follow the target language's CLDR rules, `other` required).
3. Rich text only via designated tags `<b>…</b>` and `<link>…</link>`; any other tag, HTML entity, `javascript:` or `<script` is rejected. The dashboard renders every message as plain text plus those two tags.
4. Ids not in the reference are reported as stale (error in PRs).

## 3. Module packs (`GameplanePanel/module`)

```text
modules/<name>/locales/
├── en.json   # generated by `gp-module i18n extract`
└── fr.json
```

Same Format.JS JSON rules; ids per [module-locales.md](./module-locales.md). No `meta.json` (language metadata comes from the app pack). `sourceHash` works as in app packs (first 12 hex characters of the SHA-256 of the English text) and is written by `gp-module i18n stamp`.

## 4. Generated runtime artifacts (not committed)

- `web/src/generated/i18n/<tag>.json` — `formatjs compile --ast` output, one lazy chunk per language.
- `web/src/generated/i18n/languages.json` — `[{tag,nativeName,englishName,direction,completeness,listed}]`, from `i18n-check --manifest`.
